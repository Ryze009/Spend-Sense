Spend Sense is a personal finance tracker that helps users manage their day-to-day purchases and budgets. It allows users to log expenses with automatic tax calculation, organise spending into custom categories, set category budgets, upload receipt photos, and export their data. The app supports multiple currencies, a customisable gold dark theme, and works entirely in the browser with no account required.

Tech stack:

React
TypeScript
Tailwind CSS
Vite
localStorage (no backend)
